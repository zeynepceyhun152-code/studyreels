# StudyReels

**The study app that shows its work.**

Everyone's trying to out-TikTok TikTok for studying. Almost nobody's asking the harder question: if an AI is generating what a student studies, how do you actually know it isn't making things up? StudyReels answers both — it hijacks the scroll habit *and* proves, line by line, that what it's showing you is real.

Built for the Prometheus July AI Challenge.

---

## See it in 10 seconds

1. Paste your class notes into the Hub
2. Claude turns them into a study reel — script, explanation, and quiz, grounded in what you wrote
3. Every reel gets a **🛡️ Trust Score** you can tap open and audit yourself
4. The feed learns what you actually engage with and reorders itself
5. Find a study partner by shared classes, send them a reel, ask your AI Study Buddy when you're stuck

## What it does

- **Notes → reels.** A vertical feed of study reels — POV hooks, AI-narrated footage, avatar-led explainers — each with a plain-language concept breakdown and an active-recall quiz, generated by Claude directly from what a student uploaded.
- **Trust Score — the actual differentiator.** Every generated reel is checked against the student's own source notes by a fully deterministic, rule-based engine. No second AI model quietly vouching for the first one. It flags numbers or claims that don't trace back to the notes, verifies the quiz's correct answer is actually grounded, and shows exactly which terms matched and which didn't. It even scores our own fallback template honestly — usually lower — because a trust signal that can't fail isn't one.
- **A feed that learns.** A recommender reranks what a student sees based on real interaction signals: watch time, likes, quiz accuracy.
- **Study Partners.** Matched by shared classes and curriculum, with direct reel-sharing and an always-on AI Study Buddy for explaining anything, anytime.
- **An interface built for the habit it's replacing.** Vertical swipe feed, right-side action rail, stories-style class filters — the same interaction language as the apps already winning students' attention, redirected somewhere that compounds.

## Why the Trust Score is the real pitch

Most "responsible AI" features in hackathon projects are a confidence percentage the model itself made up. Ours isn't a model at all:

1. Tokenize the generated reel and the source notes
2. Compute what percentage of key terms in the reel are actually present in the notes
3. Flag any number or statistic in the reel that doesn't appear anywhere in the source
4. Check that the quiz's correct answer is traceable to the notes, not invented

Every point in the score maps to a rule you can read in `server.js`. Nothing is a black box grading another black box.

## Tech stack

| Layer | Tech |
|---|---|
| Frontend | React (in-browser Babel), Tailwind CSS — single-page app, Instagram-inspired UI |
| Backend | Node.js, Express — one server, one URL |
| Reel generation | Claude API (Anthropic) — script, description, and quiz in one call |
| Trust Score | Custom deterministic rules engine — zero external model calls |
| Recommender | Logistic regression, trained in Colab, exported as weights and run as plain JS at runtime |
| AI Footage clips | Pre-generated with Pictory AI (script-to-video with narration) |

## Architecture notes

- **No live Python dependency.** The recommender trains offline (`ml/studyreels_recommender_training.ipynb`); the resulting weights are hardcoded into `server.js` as plain math. Zero risk of a Python service dying mid-demo.
- **Graceful degradation.** No Claude API key configured, or a request fails? Reel generation falls back to a local template instead of breaking — and the Trust Score engine still runs and scores it honestly.
- **One process.** Express serves the React frontend statically. `npm start` and you're done.

## Honest limitations

- The recommender trains on **simulated** interaction data, not real logged student behavior yet — built to be retrained on real activity as usage grows.
- AI Footage reels are **pre-generated** externally (Pictory AI), not produced live per-upload.
- Storage is in-memory for this build — no persistent database yet, resets on server restart.

We'd rather say this plainly than have a judge find it first.
